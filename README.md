# Сайт заказа доставки — кофейня «Кружка»

Лёгкий мобильный сайт на Next.js: меню с корзиной и оформление заказа в виде бумажного чека. Заказ можно отправить владельцу двумя способами — в Telegram (автоматически) или в WhatsApp (открывается чат с готовым текстом).

## Что внутри

- `app/page.js` — главная страница (меню, корзина, чек оформления)
- `app/menu-data.js` — меню, цены, стоимость доставки. **Редактируй это в первую очередь**
- `app/api/send-order/route.js` — серверная функция, которая отправляет заказ в Telegram
- `app/globals.css` — все стили сайта

## Шаг 1. Проверить сайт локально (по желанию)

Если хочешь посмотреть сайт на своём компьютере перед выкладкой:

```bash
npm install
```

Скопируй `.env.example` в `.env.local` и вставь туда свои значения (токен бота, chat_id — те же, что использовали для python-бота; они больше не нужны для самого бота, но нужны для этой функции отправки).

```bash
npm run dev
```

Открой `http://localhost:3000` в браузере.

## Шаг 2. Выложить на GitHub

Vercel разворачивает сайты из GitHub-репозитория. Если ещё нет аккаунта на github.com — зарегистрируйся (бесплатно).

1. Создай новый репозиторий на GitHub (например `coffee-order-site`)
2. Залей туда эту папку одним из способов:
   - через сайт GitHub — кнопка "uploading an existing file", перетащи все файлы
   - или через терминал:
     ```bash
     git init
     git add .
     git commit -m "первый коммит"
     git branch -M main
     git remote add origin https://github.com/твой-логин/coffee-order-site.git
     git push -u origin main
     ```

## Шаг 3. Подключить к Vercel

1. Зайди на vercel.com, зарегистрируйся через GitHub-аккаунт (бесплатно, без карты)
2. Нажми **Add New → Project**
3. Выбери репозиторий `coffee-order-site` — Vercel сам определит, что это Next.js
4. Перед нажатием Deploy — разверни раздел **Environment Variables** и добавь три переменные (значения — из `.env.example`, свои реальные):
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `NEXT_PUBLIC_WHATSAPP_NUMBER`
5. Нажми **Deploy**

Через 1-2 минуты сайт будет доступен по адресу вида `coffee-order-site.vercel.app` — уже полностью рабочий, бесплатно, без выключения.

## Как редактировать меню

Открой `app/menu-data.js` — там простой список категорий и позиций с ценами. Меняй свободно, изменения появятся на сайте после следующего деплоя (при пуше в GitHub Vercel обновляет сайт автоматически).

## Как это работает без постоянно включённого компьютера

В отличие от python-бота, здесь нет процесса, который должен работать 24/7. Функция в `app/api/send-order/route.js` "просыпается" только в момент, когда кто-то нажимает "Отправить в Telegram" на сайте, отправляет сообщение и сразу завершается. Сайт и эта функция живут на серверах Vercel — твой Mac для этого не нужен вообще.

## Про WhatsApp

Кнопка "Отправить в WhatsApp" открывает чат WhatsApp с уже готовым текстом заказа — клиенту останется только нажать "отправить". Это не полноценная автоматизация (как с Telegram), а самый простой бесплатный способ без сложной верификации бизнеса у Meta.
